# YAIL Debate Event Timer

Speaker timer for the **AI in Higher Education Showcase Debate** — 22 October 2026, Zirkus des Wissens, Linz.

## Open

Double-click `timer.html` — no install needed.

Or from the terminal:

```
yail-debate-event-timer
```

## How it works

- **5-minute countdown** per speaker. Drag the bar to adjust at any time.
- **Bell at 4:00** — single warning tone (1 min left).
- **Three bells at 5:00** — time's up.
- **Overtime** counts -0:01 → -1:00 in flashing red, with a ping every 10 seconds. Auto-stops at -1:00.
- **Next/Prev** buttons (or `N` / `P`) switch speakers and reset the timer.

## Keyboard shortcuts

| Key | Action |
|-----|--------|
| `Space` | Start / Pause |
| `R` | Reset |
| `N` / `P` | Next / Prev speaker |
| `F` | Fullscreen |
